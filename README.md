# MFCL


This repository is the official implementation of [MFCL: Multi-view feature consistency learning for cross-domain open-set mechanical fault diagnosis](https://www.sciencedirect.com/science/article/pii/S0888327025013688) (MSSP 2026).


## Requirements
- Python 3.9
- Numpy 1.16.2
- Pandas 0.24.2
- tqdm 4.31.1
- sklearn 0.21.3
- Scipy 1.2.1
- pytorch >= 1.2
- torchvision >= 0.40
